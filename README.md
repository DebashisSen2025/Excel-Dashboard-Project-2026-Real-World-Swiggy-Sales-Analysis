## 📌 Project Overview

This project analyzes and visualizes grocery sales data from Swiggy to provide actionable business insights.

The dashboard includes measurements such as total sales, average order value, category performance,
regional analysis, and trend charts — all designed for strategic business decision-making using Excel.

---

## 📈 Key Objectives

The dashboard helps answer important business questions like:

- What is the **total revenue and sales trend** over time?
- Which **product categories** contribute most to total sales?
- How do **different regions and outlets** compare in sales performance?
- What is the **average order value (AOV)** and customer engagement trend?
- Are there **seasonal patterns** or peak sales months?
- How are **ratings and feedback scores** distributed across categories?

## 📂 Dataset Overview

The analysis uses a real-world grocery dataset containing fields such as:

| Field | Description |
|-------|-------------|
| Order ID | Unique order identifier |
| Order Date | Order timestamp |
| Product Category | Category sold (e.g., Fruits, Beverages) |
| Sales Amount | Value of sales |
| Region / City | Location of order |
| Outlet Type / Size | Type of grocery outlet |
| Customer Rating | Rating provided for order |
